# 星敏感器标定转向 · 禁入区审核

高空天文台星敏感器标定转向的**纯前端**审核工具（TypeScript + React + Vite）。
操作员录入关键帧指向、统一禁入角与禁入天体，一次提交即可查看计划结论：
视轴沿**整条最短大圆弧**是否会扫过太阳、月球等禁入天体。

## 审核规则

- 关键帧 2–8 个，时刻（秒）**严格递增**；赤经 ∈ [0°, 360°]（360° 与 0° 等价），赤纬 ∈ [-90°, 90°]。
- 统一禁入角为正（度）；禁入天体 1–6 个，名称唯一。
- 拒绝：重名、赤经赤纬越界、非数值、时刻非递增、相邻指向**相同**（无转向）或**正反相对**（存在无数条等长大圆弧，最短路径不唯一）。
- 赤经环绕（如 350°→10°）与两极附近指向都先换算为单位向量再计算。

### 为什么是「真实」最小角距

每条相邻段是单位球面上的短弧：

```
p(f) = (sin((1-f)θ)·a + sin(fθ)·b) / sin θ,   f ∈ [0,1]
```

对任一禁入天体方向 u，弧上点积 `D(f) = u·p(f) = α cos(fθ) + β sin(fθ)` 是弧参数的连续函数。
最小角距要么出现在**两个端点**，要么出现在**弧内驻点** `f₀ = atan2(β, α)/θ`（使 D 取极大 √(α²+β²)）。
系统对三者做闭式比较——**不是只比端点，也不是离散取样**。

判定违规后，还会解边界方程 `R cos(fθ − δ) = cos(ρ)` 求轨迹**首次进入**禁入锥的见证时刻；
首个越界见证按「计划时刻 → 段输入顺序 → 天体输入顺序」排序给出。

草稿的任何修改都会立即撤下上一次结论，必须重新点击「提交审核」。

## 本地开发

```bash
npm install
npm test        # vitest 单元测试（含解析解与 2 万点取样的随机对照）
npm run build   # tsc 类型检查 + 生产构建到 dist/
npm run dev     # 本地开发服务器
```

## Docker

静态服务（nginx），宿主机端口可通过 `HOST_PORT` 配置（默认 8080）：

```bash
docker compose up -d --build
# 自定义端口
HOST_PORT=9000 docker compose up -d
curl http://localhost:8080/healthz   # -> ok
```

一次性审核服务 `verify`：运行单元测试与生产构建，完成后自行退出，
**退出码即审核结果**（0 通过，非 0 失败），适合接入 CI：

```bash
docker compose run --rm verify
echo $?
```
